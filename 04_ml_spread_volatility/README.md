# Machine Learning for Commodity Spreads & Volatility

## Research proposal
**Question:** Do machine-learning models improve out-of-sample spread or volatility forecasts?

**Scope:** Baseline regressions, Random Forest/boosting, walk-forward validation, leakage checks.

**Motivation:** Connect probability, stochastic calculus, and statistical modeling to practical soft-commodity research.

## Plan
1. Define hypothesis and mathematical assumptions.
2. Document data, units, contract conventions, and cleaning steps.
3. Implement transparent baseline before advanced models.
4. Validate chronologically and quantify uncertainty.
5. Write findings, failure cases, and next steps.
